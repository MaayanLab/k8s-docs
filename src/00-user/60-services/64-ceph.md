# Ceph Object Storage (S3)

[Ceph](https://ceph.io/en/) is an reliable and scalable storage solution we have running on our cluster. It automatically provisions hard drives connected to our systems and redundantly stores data across them.

[Ceph Object Storage](https://ceph.io/en/discover/technology/#object) provide a Simple Storage Service (S3) API on top of our Ceph cluster.
